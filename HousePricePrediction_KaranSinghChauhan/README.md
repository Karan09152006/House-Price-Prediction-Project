A Machine Learning project that predicts house prices using different regression algorithms. This project demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis (EDA), feature engineering, model training, evaluation, and visualization.

---

## 📌 Project Overview

The objective of this project is to accurately predict house prices based on various housing features such as area, number of bedrooms, bathrooms, parking, furnishing status, and other property characteristics.

The project compares multiple regression algorithms and evaluates their performance using standard regression metrics.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/House-Price-Prediction.git
```

Go to the project directory

```bash
cd House-Price-Prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run Jupyter Notebook

```bash
jupyter notebook
```
